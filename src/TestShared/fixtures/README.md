## `import/` and `import-carriers.csv` (`docs/operations/blind-run.md`)

Ten synthetic files of mixed types, copied from corpus v3 (`lossrun eval generate --seed 8`) into carrier folders, as an archive share might hold them. Plus a 150 dpi PNG at the root (its carrier comes from `import-carriers.csv`) and a `.txt` that `lossrun eval import` must skip. The carrier map sits outside `import/`, so it is not imported as a CSV. Its folder rows name the two carriers whose names end in "." (Windows drops the trailing dot from folder names). Used by `ImportTests` and `docs/evaluation/results/2026-10-23-blind-run-proof/`.
