## The quote system's one rule (ADR 0024)

The real quote system replaces the mock behind the same `PUT /quotes/{id}`, `POST /quotes/{id}/{collection}` contract. Beyond the `Idempotency-Key` it already has to honour (a repeated key returns the first answer and changes nothing), it must implement exactly one more rule. Each `quote.payload` body (and Service Bus property) carries `quoteRevision`, which increases with every change to the quote's data: upload completed, review decided, reopened decision, override. The receiver keeps the highest revision it has applied and answers **409 with error code `stale-revision`** to a lower one, changing nothing. The dispatcher records that as `superseded` and neither retries nor dead-letters it, because a newer command already reached the quote. A receiver that fetches the full payload uses the pinned `quotePayloadUrl` (`?revision=<n>`): 409 `revision-superseded` there means a newer revision exists. `ETag: "q-<n>"` and `If-None-Match` let it poll cheaply.

## Order of steps in the client tenant

1. **Subscription and quota.** Create the subscription and resource group. Request these and wait for them (they gated this POC: ADRs 0001, 0003, 0004):
   - Azure OpenAI Data Zone capacity: `gpt-5.4-mini`, `text-embedding-3-large`, and the learn model;
   - Content Understanding;
   - Azure SQL in the chosen region;
   - AI Search.
2. **Terraform apply.** Run it with a client `environments/<env>.tfvars` (start from `sandbox.tfvars.example`; ADR 0027). Set `create_entra_app = true` if the identity team allows it; otherwise they create the app registration and hand over `auth_tenant_id` / `auth_audience`.
3. **Entra app roles.** Map the six app roles (Applicant, Underwriter, UWManager, Admin, Engineer, QuoteSystem) to client groups or service identities, with PIM for Admin. HTTP Basic is refused outside the POC environment (artefact 6, ADR 0027).
4. **Schema deploy.** `lossrun-db deploy --param appPrincipalName=<function app>`, then `lossrun-db audit-proof`.
5. **Blind set from the keyed archive.** The actuarial and UW team seal 300–500 documents (`sealed-set-protocol.md`) and release the ~100-document tuning set. Run the blind set once and score it.
6. **Shadow period, 30 days.** Run alongside the manual process. Compare re-keying minutes, quote cycle time and accuracy on real submissions before cut-over.
